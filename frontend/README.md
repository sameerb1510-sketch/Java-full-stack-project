# Forge Fitness Club frontend

React single-page client for the gym membership manager. It uses React Router and Vite, with plain CSS for styling.

From this folder, run:

```powershell
npm install
npm run dev
```

The Vite app uses the Spring Boot API at `http://localhost:8080` by default. Set `VITE_API_URL` only when the API runs at a different address. See the project-root `README.md` for the full application setup.
