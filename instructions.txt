MINI PROJECT (from the manual)

The mini project is a full-stack application for 1 to 3 students that combines everything learned in the course: Core Java/OOP, client-side web technologies, server-side Java, and a modern front end. You choose a small real-world problem (suggested: Student Feedback System, Online Examination Module, Library Book Tracker, Event Registration Portal, Employee/Attendance Management) and build it with either React + Spring Boot + MySQL or Servlet/JSP + MySQL.

Objectives: choose a problem sized for the team, design the database schema and the REST API (or Servlets/JSP), build a React (or HTML/CSS/JS) front end that uses the backend, implement at least one complete CRUD workflow end to end, and document the design decisions and demonstrate the working app.

Modules of the system:

Front end: pages/components, forms, client-side validation, routing if React.
Backend: Controller, Service, Repository, Entity layers for Spring Boot, or Servlet + JDBC + JSP views.
Database (MySQL): schema design, relationships, sample data.
Integration: REST calls with fetch/axios, or form submissions to servlets.
Documentation: problem statement, ER diagram, user manual, test cases.

Procedure: finalize the problem statement and schema, build entities, repositories/DAOs, services and controllers/servlets, build front-end components, forms, routing and state, integrate front end and back end, test all workflows with validation and exception handling, then prepare the documentation and final demo.

Evaluation (100 marks): CO3 implement backend and front-end correctly, 25 marks (Apply). CO4 identify and fix runtime errors and handle exceptions across layers, 20 marks (Analyze). CO5 evaluate design choices for scalability and maintainability, 15 marks (Evaluate). CO6 design and integrate a complete full-stack solution, 20 marks (Create). Documentation, viva voce and code quality, 20 marks.

Deliverables: a working full-stack application, an ER diagram or schema document, well-commented source code as a .zip or Git link, a project report (problem statement, design diagrams, screenshots, test cases, conclusions), and a live demo of at least one complete CRUD workflow.

Future enhancements the manual suggests: JWT login, Docker, splitting into microservices, and unit/integration tests (JUnit, React Testing Library).

SYLLABUS

Module 1, Introduction to OOP and Java Basics (5 hours): JDK, JRE, JVM, data types, variables, methods, operators, expressions, if-else and loops, arrays and strings. OOP concepts: objects, classes, encapsulation, abstraction, inheritance, polymorphism, message passing, constructors and their types, static members, method overloading, input/output in Java, packages (built-in and user defined). Self learning: Vectors in Java.

Module 2, Inheritance, Exception Handling and Multithreading (6 hours): types of inheritance, method overriding, super, abstract classes and methods, final, multiple inheritance using interfaces, extends. Exception handling: try, catch, finally, throw, throws, multiple catch blocks. Multithreading. Self learning: user defined exceptions.

Module 3, Client Side Programming (5 hours): HTML (elements, attributes, links, images, tables, lists, frames, forms), CSS3 (syntax, inclusion, colors, backgrounds, fonts, tables, lists, selectors), and JavaScript (conditionals, loops, functions, arrays, objects, control flow, Math, BOM, DOM). Self learning: loading a text file into a page using AJAX.

Module 4, Advanced Java Concepts (5 hours): JDBC architecture, drivers, connecting to MySQL/Oracle, executing SQL with Statements. Servlets: lifecycle, request, response, context, HTTP sessions, handling forms. Session management and JSP: architecture, page directives, components, scripting elements, standard actions, method definitions, JSTL. Self learning: database connectivity in servlets.

Module 5, Web Programming using React JS (5 hours): MVC architecture, MVC with servlets and JSP, developing a complete web application, company use cases. React: components and elements, rendering, state and props, events, hooks, routing, conditional rendering, lists and keys, forms, building a single page application. Self learning: unidirectional data flow in FLUX.

Module 6, Spring Boot for Microservices (4 hours): introduction to microservices, dependency injection and inversion of control, Spring annotations, database integration, creating Spring Boot applications, building RESTful APIs.
